The research question

Can a model revise a reasonable conclusion?

Incomplete information often calls for a default inference. When new context introduces an exception, that inference may no longer be justified. CDR-Dataset focuses on this transition.

01 / INFER

Contextual default reasoning

Draw defeasible conclusions from the available context: conclusions that remain open to revision.

02 / REVISE

Belief retraction

Withdraw a previously supported conclusion when new context defeats its justification.

LEGAL CASES / IsGuilty

Is this person guilty?

The act stays the same: intentionally damaging another person’s property without consent. The stipulated necessity feature is true.

Context c_1 · Ordinary situation

Property damage, with no exception.

There is no imminent serious danger or official duty. The hypothetical rule provides no applicable exception.

1Guilty

Intentional damage to another’s property without consent satisfies the supplied offence in this context.

v1 · case 007 · c_1 → c_2 · GPT-5.4 reference

The key idea: a conclusion supported in one context can lose its support in another. The instance features remain fixed; the context changes.

Labels shown here are stored teacher references, not live model predictions. The Guilty example follows a supplied hypothetical offence and its exceptions.
