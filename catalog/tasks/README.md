# Tasks

Each directory defines a general task (`task.yaml`) and its contexts
(`contexts.yaml`). Class-specific query wording lives in task bindings.

Start with [fly/task.yaml](fly/task.yaml) and [fly/contexts.yaml](fly/contexts.yaml).
Fly judgments belong in `labels/<source>/tasks_per_context/fly.json`. Other tasks retain their previous files. See [catalog storage](../README.md).
